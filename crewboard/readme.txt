Einfaches Mitgliederportal und Dienstplanung als Erweiterung für Events Manager.

== Beschreibung ==

CrewBoard ergänzt Events Manager um Dienste, Helferzuweisung, Teams und einen reduzierten Mitgliederbereich.

Version 0.2.0 enthält:
* CrewBoard-Mitgliederverwaltung unabhängig von WordPress-Rollen
* Stufen Mitglied, Koordinator und Vorstand
* Teams: Theke, Technik, Einlass, Aufbau, Reinigung, Booking und Einkauf
* Teamgebundene Dienste
* Zuweisung vorhandener WordPress-Benutzer
* Eigene CrewBoard-Veranstaltungsverwaltung für Koordinatoren
* Optionale Selbstzuweisung für freie Dienste
* Persönliche Dienstübersicht und Terminagenda

== Installation ==

1. ZIP unter Plugins > Installieren > Plugin hochladen installieren.
2. Plugin aktivieren.
3. Unter CrewBoard > Mitglieder Personen freischalten und Teams zuordnen.
4. Unter CrewBoard > Veranstaltungen Dienste anlegen und Personen zuweisen.
5. Mitglieder öffnen die automatisch angelegte Seite /intern/.
